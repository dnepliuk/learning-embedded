# Модуль 4.1 — UART між STM32 та ESP32-S3

Навчальний проєкт двонапрямленого керування світлодіодами через UART.

## Як працює

- Натискання ручки енкодера на ESP32-S3 перемикає світлодіод STM32.
- Натискання кнопки на STM32 перемикає світлодіод ESP32-S3.
- Одне натискання — одне перемикання. Брязкіт контактів фільтрується протягом 25 мс.

Обмін працює на **115200 бод, 8N1**, без апаратного керування потоком. Команди `LED:1\n` та `LED:0\n` вмикають і вимикають світлодіод отримувача. Поточний бажаний стан повторно надсилається щосекунди для відновлення після перезапуску іншої плати.

## Підключення

| ESP32-S3 (UART1) | STM32 (USART2) |
|---|---|
| GPIO17 — TX | PA3 — RX |
| GPIO16 — RX | PA2 — TX |
| GND | GND |

- **ESP32-S3:** зовнішній LED на GPIO5 через струмообмежувальний резистор, катод до GND; контакт SW енкодера на GPIO4, натискання замикає його на GND. CLK/DT енкодера не використовуються.
- **STM32:** LED на PC13, активний низький рівень; кнопка між PA0 та GND.
- Для обох входів кнопок увімкнена внутрішня підтяжка до живлення.

## Структура та запуск

- `uart_stm/` — проєкт STM32CubeIDE на HAL. Зібрати, прошити через ST-LINK.
- `uart_esp/` — проєкт PlatformIO з ESP-IDF для `esp32-s3-devkitm-1`. Виконати Build → Upload → Monitor; швидкість монітора — 115200, порт вибрати відповідно до підключеної плати.

Після запуску обох плат перевірити керування в обох напрямках. У моніторі ESP32 повідомлення `TX` позначають надсилання команд, а `RX` — отримання.
