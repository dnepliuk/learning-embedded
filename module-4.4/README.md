Модуль 4.4 — навчальний проєкт для ESP32-S3 на ESP-IDF і PlatformIO: датчик BME280 через SPI вимірює температуру, вологість і атмосферний тиск, а OLED SSD1306 показує їх разом із часом і датою годинника DS1307, підключеного через I²C. Екран і повідомлення Serial Monitor оновлюються кожні 500 мс; для роботи з BME280 використовується бібліотека Bosch із `src/vendor/bosch`. Збірка виконується командою `pio run`, прошивання — `pio run -t upload`, відкриття монітора — `pio device monitor` зі швидкістю 115200 бод. Щоб установити місцевий час, введіть у моніторі `TIME YYYY-MM-DD HH:MM:SS`, підставивши потрібні дату й час, і натисніть Enter; під час перезапуску програма не перезаписує RTC.
